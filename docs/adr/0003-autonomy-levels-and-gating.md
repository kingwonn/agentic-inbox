# ADR 0003: 自主等级（L1–L5）由 LLM 提议、策略引擎钳制、硬性红线强制审批

- 状态：已采纳（2026-11-05）
- 决策：等级判定 = `min(LLM 提议, policy.max_level[category], 能力可用性上限, 置信度修正, 用户覆盖)`。敏感动作（对外通信、发布、推送受保护分支、PR 创建/合并、删除、支付、凭据变更、策略列表中的 Bash 模式）在任何等级都通过 `canUseTool` 门控进入 Outbox。
- 理由：LLM 善于理解任务语义，但不应单独决定权限；确定性规则可审计、可配置、可测试。
- 后果：`config/policy.yaml` 成为权限的唯一真相来源；看板展示每个任务的等级与钳制原因。
